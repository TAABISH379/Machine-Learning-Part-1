# Machine Learning Part 1

This project explores heart disease data with Python and machine learning.

## Contents

- `Untitled.ipynb` - notebook containing data loading, exploratory analysis, visualizations, preprocessing, and machine learning work.
- `heart.csv` - heart disease dataset used by the notebook.
- `anaconda_projects/db/project_filebrowser.db` - project metadata generated by Anaconda.

## Requirements

Install the Python packages used by the notebook:

```bash
pip install pandas matplotlib seaborn scikit-learn jupyter
```

## Usage

1. Open `Untitled.ipynb` in Jupyter Notebook, JupyterLab, or VS Code.
2. Make sure `heart.csv` is in the same directory as the notebook.
3. Run the notebook cells from top to bottom.

## Dataset

The dataset contains patient features such as age, sex, chest pain type, blood pressure, cholesterol, maximum heart rate, and an indicator for heart disease.
